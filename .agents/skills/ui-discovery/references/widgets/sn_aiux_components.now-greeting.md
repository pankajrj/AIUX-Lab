# Greetings

`sn_aiux_components.now-greeting` · platform · sdk-built

A greeting display widget that shows a personalized welcome message with the current user's name fetched from the server. Displays "Welcome, [Name]!" followed by a customizable help prompt. Features loading spinner during data fetch and fallback to "Welcome, Guest!" on error.

**Best for:** Displaying a personalized welcome message on landing pages or home screens. Ideal for portal homepages, dashboard headers, or any page where you want to greet users by name and prompt them for action.

## Import

```js
import '@servicenow/glide-widgets/sn_aiux_components/now-greeting';
```

Then use `<now-greeting>` in a template.

## Notes

- Has a server script — data is fetched server-side. The source below includes it as `(server script)`. Read it before calling `this.server.get(input)`: it defines which `input` keys are honored and what shape lands in `data`. An input key it does not read is silently ignored — the call succeeds and nothing happens.
