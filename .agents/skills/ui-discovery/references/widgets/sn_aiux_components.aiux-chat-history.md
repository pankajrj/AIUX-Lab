# Chat History

`sn_aiux_components.aiux-chat-history` · platform · sdk-built

A chat history widget that renders the ServiceNow LBF chat client in HISTORY mode. Displays previous chat conversations without message input capabilities, using the AIUX channel for communication.

**Best for:** Displaying chat conversation history in a read-only view. Use when you need to show past conversations without the ability to send new messages, such as in a history panel or conversation archive.

## Import

```js
import '@servicenow/glide-widgets/sn_aiux_components/aiux-chat-history';
```

Then use `<aiux-chat-history>` in a template.
