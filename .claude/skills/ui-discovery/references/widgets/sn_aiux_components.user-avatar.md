# User Avatar

`sn_aiux_components.user-avatar` · platform · sdk-built

A user avatar widget that fetches and displays user profile information including avatar image or initials fallback, online presence indicator, and optional username display with profile navigation. Supports multiple sizes (xxs, xs, sm, md, lg), skeleton loading states, and automatic data fetching by sys_id.

**Best for:** Displaying user profile pictures or initials with optional online status indicators and usernames. Ideal for activity streams, comments, chat interfaces, user lists, and anywhere user identification is needed.

## Import

```js
import '@servicenow/glide-widgets/sn_aiux_components/user-avatar';
```

Then use `<user-avatar>` in a template.
